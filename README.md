# Cafeteria Triple Espresso

A Cafeteria Triple Espresso é o quarto projeto do programa de desenvolvimento web da TripleTen. Ela foi criada usando HTML e CSS, com base no roteiro e seguindo as diretrizes da metodologia BEM para estruturação e organização do código.
