# Project 4: Triple Espresso Coffee Shop

The **Triple Espresso Coffee Shop** is the fourth project in the TripleTen Web Development Program. The goal of this project was to build a modern coffee shop landing page based on a provided design brief, using the BEM methodology to create a well-structured and maintainable codebase.

## Live Demo

Visit the live demo here: **[Triple Espresso Coffee Shop](https://biancabaccin.github.io/web_project_coffeeshop/)**

## Technologies

- HTML5
- CSS3
- BEM Methodology
- HTML Forms
- Embedded Videos (YouTube)

## Project Purpose

This project was created to practice:

- Building semantic and accessible web pages
- Structuring CSS using the BEM methodology
- Creating responsive and visually appealing layouts
- Embedding videos into a webpage
- Creating and styling HTML forms
- Following a design brief with attention to detail
